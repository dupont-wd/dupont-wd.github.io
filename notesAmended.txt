General terminology about GitHub

GitHub repository view: 

This describes the root content of the repository. Its url contains the text GitHub.com and there is no extension. An example is https://github.com/vubiostat/ps . If there is readable output on this page it will be in a file called README.md. Clicking on this file opens this text. Clicking on Code shows the underlying code. For the most part, the notes given below are the easiest way to modify GitHub pages. You may need to use the GitHub app to make direct modifications.

GitHub .io view

This is the rendered page. Its URL ends with the extension.io and typically shows the desired product. An example is https://dupont-wd.github.io/ . But sometimes .io pages look like repository pages (e.g. https://github.com/dupont-wd/dupont-wd.github.io ) So I am a little confused about this.

Local version

We can maintain local versions of GitHub pages on our desktop. These files can be edited and posted back to GitHub. This is the way that GitHub pages are edited.


Notes for updating and posting GitHub page


Open index.Rmd in Rstudio.  You may need to install packages if there is a notice saying they are missing

Edit this file as needed.  The edits can be done in either Rstudio or in TextPad. If you use TextPad you must reload the index file into RStudio

In Rstudio click on Knit.  This will create an updated index.html file in the same directory as the .Rmd file

Click on this file to make sure it looks ok.

Repeat for data.Rmd and data.html files if modified.

Open GitHib Desktop Application from start menu.  Open Start menu. Type GitHub in search bar. Click the GitHub Desktop app link under best matches.

In GitHub Desktop select the dupont-wd.github.io repository in the upper left hand Drop Down under the menu bar.

The app will now display any uncommitted modifications to repository in Left hand side bar. Click on each entry to view changes in the file difference window to the right. Verify that the changes are what you expect.

In the summary text box in the lower part of the sidebar type a short description of the modifications made to the files.

If you wish you can put a more detailed description of the changes in the Description Text Area below the Summary Text Box.

Click the Commit Button below the description text area.

Next Push the commits to GitHub by pushing the Push to Origin button in the Upper Right below the menu bar.

Then go to https://github.com/dupont-wd/dupont-wd.github.io

Click on Add file and select Upload files.

Drag the new index.html file into the indicated area. I have also dragged the index.Rmd file here although I do not know if it is necessary.
Click on Commit changes.

Go to https://dupont-wd.github.io/ to check that the revised file has been uploaded.

N.B. If you are making edits to the previous index.html file it may take a few minutes before the revised file is published on GitHub.

See index.Rmd in Rstudio to see the syntax for linking two html files together. I have used this syntax to link data.html to my main index.html file.
