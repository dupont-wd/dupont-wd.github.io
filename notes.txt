Notes for updating and posting GitHub page

Open index.Rmd in Rstudio.  You may need to install packages if there is a notice saying they are missing

Edit this file as needed.  The edits can be done in either Rstudio or in TextPad. If you use TextPad you must reload the index file into RStudio

In Rstudio click on Knit.  This will create an updated index.html file in the same directory as the .Rmd file

Click on this file to make sure it looks ok.

Then go to https://github.com/dupont-wd/dupont-wd.github.io

Click on Add file and select Upload files.

Drag the new index.html file into the indicated area. I have also dragged the index.Rmd file here although I do not know if it is necessary.
Click on Commit changes.

Go to https://dupont-wd.github.io/ to check that the revised file has been uploaded.

N.B. If you are making edits to the previous index.html file it may take a few minutes before the revised file is published on GitHub.

See index.Rmd in Rstudio to see the syntax for linking two html files together. I have used this syntax to link data.html to my main index.html file.
